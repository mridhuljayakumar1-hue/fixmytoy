# 🧸 Fix My Toy - Professional Toy Repair & Restoration Hospital

A modern, dynamic, and interactive web application for **Fix My Toy** — a premier repair & restoration hospital for vintage toys, plushies, electronics, and ride-on vehicles.

## 🔗 Live Demo & Repository
- **Live Website**: [https://mridhuljayakumar1-hue.github.io/fixmytoy/](https://mridhuljayakumar1-hue.github.io/fixmytoy/)
- **GitHub Repository**: [https://github.com/mridhuljayakumar1-hue/fixmytoy.git](https://github.com/mridhuljayakumar1-hue/fixmytoy.git)

---

## ✨ Key Features

- 🏥 **Interactive Cost & Repair Estimator**: Real-time price and repair time calculation based on toy type and damage severity.
- 🔍 **Live Repair Status Tracker**: Search sample or custom tracking numbers to monitor real-time repair progress across hospital stages.
- 🎚️ **Before & After Restoration Slider**: Visual comparisons showing toy transformations.
- 📍 **Interactive Location Finder**: Hospital branch locator with store hours, directions, and phone numbers.
- 💬 **Instant WhatsApp Consultation**: Floating direct button for quick customer support.
- 📱 **Fully Responsive & Modern UI**: Built with React, Vite, Tailwind CSS, and Lucide Icons.

---

## 🛠️ Tech Stack & Dependencies

- **Frontend**: React 18, Vite 4
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Icons**: Lucide React
- **Effects**: Canvas Confetti
- **Deployment**: GitHub Pages (`gh-pages`)

---

## 🚀 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mridhuljayakumar1-hue/fixmytoy.git
   cd fixmytoy
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

---

## 📦 Deployment to GitHub Pages

To build and deploy updates to GitHub Pages:
```bash
npm run deploy
```
*(This automatically runs `npm run build` and publishes the `dist` directory to the `gh-pages` branch).*
